# Interactive Cell Visualization

An interactive 3D visualization of a cell using Three.js.
https://content-interactives.github.io/cells/

## Description

This project creates an immersive 3D visualization of a cell structure using WebGL and Three.js. The visualization includes detailed textures and interactive elements.

## Setup

1. Clone the repository
2. Start a local server (e.g., using Python's built-in server):
   ```bash
   python3 -m http.server 8000
   ```
3. Open your browser and navigate to `http://localhost:8000`

## Technologies Used

- Three.js
- HTML5
- CSS3
- JavaScript
